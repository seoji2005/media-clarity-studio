# 10월 데스크톱 출시를 위한 에이전트 작업 가이드

2026-09-05. 기존 `AGENTS.md`의 권한·Gate·문서 읽기·독립 리뷰·exact-HEAD 병합 규칙을 대체하지 않는다.
이 문서는 새 기능·모델·의존성·외부 비용의 포괄 승인이 아니다.

## 목표와 적용 범위

오너의 1차 목표는 **2026년 10월 중순 휴가에 Windows 데스크톱에서 실사용**이다.
NAS와 비디오 생성은 이번 출시의 선행 조건이 아니다. 정확한 휴가 시작일은 미확정이다.
기본 사용자는 편집자가 아닌 감상자다. 공개·허가·합성 비민감 자료로 개발하고 개인 민감 미디어는 외부 전송하지 않는다.
기존 과제 의무·TASK-031 8/12·TASK-032 평가 계약과 모델 채택 기준은 이 가이드에서 변경하지 않는다.
ASR·번역·실사 화질 개선의 품질 목표를 빠른 출시나 테스트 수로 대신하지 않는다.

## 작업 시작: 기존 TASK 또는 PR 본문에 한 번만 기록

- 사용자 행동 또는 제거할 구체적 실패를 한 문장으로 적는다. 새 형식 문서를 중복 생성하지 않는다.
- 정상·실패·재시작 등 필요한 수용 사례와 사용할 명령을 정한다.
- 변경 경로, 기존 Gate, 비범위, 실행 환경의 제한을 고정한다.
- 원본 불변·민감 정보·외부 비용·오너 승인 경계는 기존 규칙을 그대로 따른다.
- 기존 fixture/receipt/승인 사실을 재사용하되 실제 HEAD·환경과 맞는지 확인한다.
- 하위 에이전트는 독립 질문에만 사용한다. 기존 동시 쓰기 상한과 파일 소유권을 늘리지 않는다.

반복 실패는 더 긴 프롬프트로 덮지 않고 누락된 도구·불명확한 계약·재현 실패를 분류한다.
재시도와 escalation은 `AGENTS.md` §3.8을 재사용한다. 별도 무한 반복기를 추가하지 않는다.

## 빠른 검사: GNU Make가 필요 없는 선택적 진입점

```bash
python scripts/dev_verify.py --test test_dev_verify.py
python scripts/dev_verify.py --test test_artifact_store.py --test test_job_runtime.py
python scripts/dev_verify.py --full
```

`--test`는 정확한 기존 파일만 실행하며, 변경 영향에 필요한 테스트 선택은 작성자·reviewer가 한다.
자동 영향 분석이나 전체 회귀 대체 기능이 아니다. 없는 파일·경로/glob·0개 테스트·전부 skip은 성공이 아니다.
`--full`은 기존 `make verify`의 compile → unittest → TASK-022 smoke 순서를 Python으로 실행한다.
기존 `make verify-task-*`의 추가 mutation 감사·fixture 검사는 합치거나 없애지 않는다. Gate가 요구하면 따로 실행한다.
이 도구 자체는 설치·다운로드·비용 집행·Git 쓰기·병합을 하지 않는다. 테스트 코드를 격리하거나 network를 차단하는 sandbox는 아니다.
기존 승인 범위의 신뢰하는 테스트에만 사용한다. compile은 기존처럼 bytecode를 만들 수 있다.

## 사용자 결과와 준비 결과를 분리

작업 결과에는 확인한 것을 그대로 표시한다: 계약 검증 / 합성 통합 / 실제 모델 결과 / Windows 비GPU / 목표 RTX / 사용자 품질 평가.
이는 새로운 schema나 중앙 인증 시스템이 아니라 PR 보고 방식이다. 검증하지 않은 단계는 미검증으로 남긴다.
UI는 실행하지 않은 버튼·placeholder를 완료로 표시하지 않는다. 브라우저/실제 backend 확인이 없으면 그 한계를 적는다.
모델 후보에 실제 결과가 생기면 소규모 사용자 흐름에 연결할 계획을 세우되, 현 평가·승인 계약을 우회하지 않는다.

가까운 사용자 흐름의 수용 사례(해당 기능의 별도 승인·구현 때 사용):

| 행동 | 수용 사례 |
|---|---|
| 등록·감상 | 허가된 영상 등록 → 카드 하나 → 원본 재생 → 재시작 후 이어보기 |
| 자막 | 실제 ASR·한국어 번역 → 올바른 영상·시간축에 연결; fixture 자막은 모델 증거 아님 |
| 개선본 | 실사·빠른 동작의 원본/결과 비교; 개선본 실패가 원본을 훼손하지 않음 |
| 복구 | 중단·재개 후 완료 결과 재사용, 실패·미완료를 정상으로 표시하지 않음 |

보관함·UI·GPU 실행을 이 문서 작성으로 완료했다고 표시하지 않는다. 10분 성공을 40~120분 지원으로 일반화하지 않는다.

## 리뷰와 비용

필수 finding은 승인된 요구·안전·호환성을 해치는 재현 가능한 결함 또는 근거 있는 설계 문제다.
선택적 스타일/다듬기와 무관한 새 기능은 Nit/후속 제안으로 구분한다. 기존 Gate의 필수 검증을 줄이지 않는다.
PR 수·코드 줄 수·모델 가동시간이 아니라 작동하는 사용자 흐름, 재작업, 오너 개입, 검증 환경과 실제 품질을 본다.
시간/토큰/비용은 측정할 수 있을 때 기록하고 없으면 미측정으로 남긴다. 4.5배·10배 생산성은 목표나 보증이 아니다.

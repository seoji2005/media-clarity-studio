## 6. 반례 2 계산표 — `lines[]` 결합 구분자

**입력 (REVIEW-003 §3.2)**

```
가설 cue = [0,4)
lines = ["A", "B"]
문자·단어 타이밍 없음

```

**조문만 보고 직접 계산한 경로**

| 단계 | 근거 조문 | 적용 | 결과 |
|---|---|---|---|
| 1 | **C0** — `raw_cue_text = lines.join(U+0020 SPACE)`, 규칙 1 "모든 인접 `lines[]` 사이에 **정확히 한 개**의 U+0020" | `"A"` + `" "` + `"B"` | `raw_cue_text = "A B"` |
| 2 | **C0 규칙 2** — 줄 내용을 암묵적으로 trim하거나 빈 줄을 삭제하지 않음 | 변형 없음 | `"A B"` 유지 |
| 3 | **C0 규칙 3** — `join` 후 `norm-v1`을 **정확히 한 번** (줄 단위 선정규화 금지) | `norm-v1("A B")` (이 예시는 U+0020 보존) | `canonical_cue_text = "A B"` |
| 4 | **C0 규칙 4·5** + 알고리즘 **D** — N은 `canonical_cue_text`의 grapheme cluster 수. 남은 구분자도 **grapheme 시퀀스의 일부이며 건너뛰지 않음** | `A`, `U+0020`, `B` | **N = 3** |
| 5 | **C3** — `d = (t_end − t_start) / N` | `d = 4 / 3 ≈ 1.33333` | — |
| 6 | **C3** — k번째 grapheme 구간 `[t_start + k·d, t_start + (k+1)·d)`, 중앙 `t_start + (k+0.5)·d` | k=0 `[0, 1.3333)` / k=1 `[1.3333, 2.6667)` / k=2 `[2.6667, 4.0)` | — |
| 7 | 같은 식 | 중앙: `A` = 0.66667, `SPACE` = 2.00000, `B` = 3.33333 | 실수 재계산으로 확인 |
| 8 | **§4.4 귀속 규칙** — 중앙 시각이 정답 무음 안이면 귀속, 경계는 `[start, end)` | `0.667 ∉ [3.2,4)` / `2.0 ∉ [3.2,4)` / `3.33333 ∈ [3.2,4)` | **무음 귀속 문자 수 = 1** |

**요청받은 10개 확인 항목**

| # | 확인 항목 | 근거 | 결과 |
|---|---|---|---|
| 1 | `raw_cue_text = lines.join(U+0020 SPACE)`인가 | C0 코드블록 + 규칙 1 (`""` 결합·다른 문자 결합 금지) | **예** |
| 2 | raw text가 정확히 `"A B"`인가 | 위 1단계 | **예** |
| 3 | `norm-v1`이 join 후 **정확히 한 번** 적용되는가 | C0 규칙 3 | **예** |

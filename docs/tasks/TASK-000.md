## 0. 이 파일이 소급 기록인 이유 (부트스트랩 예외)

`AGENTS.md` §6은 **모든 작업이 TASK 파일 하나로 정의된다**고 규정합니다.
그런데 Phase 0의 최초 문서 기반 작업에는 TASK 파일이 없었습니다.
**TASK 파일 형식 자체가 그 작업의 산출물이었기 때문입니다.** 닭과 달걀 문제입니다.

REVIEW-001이 이 공백을 지적했습니다. 규칙이 자기 자신의 첫 적용 사례를 설명하지 못하면,
다음 에이전트가 "그때는 됐으니 나도 TASK 없이 시작해도 된다"고 해석할 수 있습니다.

**따라서 이 파일은 이미 끝난 작업을 사후에 기록합니다.**

| 규칙 |
|---|
| TASK-000은 **1회성 예외이며 이미 닫혔습니다** (`Status: Done`) |
| **이후 어떤 작업도 이 예외를 원용할 수 없습니다** |
| 새 작업은 반드시 TASK 파일을 **먼저** 만들고 시작합니다 |

근거 규정: [`../../AGENTS.md`](../../AGENTS.md) §6.2
